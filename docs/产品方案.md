## 1. 产品定位与目标用户
- **一句话**: 用户在交互地图上记录「去过哪、拍了啥、写了啥」,可时间回顾、看统计、一键生成可分享足迹图/公开页。
- **目标用户**: 爱旅行、想沉淀回忆的个人用户;兼顾「晒给朋友看」的轻分享需求。
- **核心情绪**: 明亮、治愈、手帐感,记录是享受而非负担。

## 5. 数据模型与 RLS(genie-tcb-db-integrator 专家)
> 建表/RLS 必须通过 TCB 脚本,且**先经用户批准启用 TCB 环境**(`ensure-cloudbase-env.sh`)。一次只执行一条 SQL。

### 5.1 表 `checkins`(核心表)
```sql
CREATE TABLE checkins (
  id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  user_id TEXT NOT NULL DEFAULT auth.uid(),
  place_name TEXT NOT NULL,
  address TEXT,
  lng DOUBLE PRECISION NOT NULL,
  lat DOUBLE PRECISION NOT NULL,
  category TEXT NOT NULL DEFAULT 'scenery',   -- scenery/food/culture/city/family/outdoor
  status TEXT NOT NULL DEFAULT 'visited',      -- visited(去过)/wish(想去)
  visit_date DATE,
  mood_text TEXT,
  tags TEXT[] DEFAULT '{}',
  photos JSONB DEFAULT '[]',                    -- [{url, thumb, caption}]
  rating INTEGER CHECK (rating BETWEEN 1 AND 5),
  is_public BOOLEAN DEFAULT false,              -- 是否纳入公开分享页
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);
COMMENT ON TABLE checkins IS '用户旅行打卡记录(去过/想去共用本表,靠 status 区分)';
CREATE INDEX idx_checkins_user ON checkins(user_id);
CREATE INDEX idx_checkins_status ON checkins(status);
```

### 5.2 表 `profiles`(公开页资料,可选第一期)
```sql
CREATE TABLE profiles (
  id TEXT PRIMARY KEY,            -- = auth.users.id
  display_name TEXT,
  avatar TEXT,
  bio TEXT
);
```

### 5.3 RLS 策略
- 私人数据(本人增删改查)—— 用 Pattern 2(owner-only):
  ```sql
  ALTER TABLE checkins ENABLE ROW LEVEL SECURITY;
  CREATE POLICY select_own ON checkins FOR SELECT TO authenticated USING (user_id = auth.uid());
  CREATE POLICY insert_own ON checkins FOR INSERT TO authenticated WITH CHECK (user_id = auth.uid());
  CREATE POLICY update_own ON checkins FOR UPDATE TO authenticated USING (user_id = auth.uid());
  CREATE POLICY delete_own ON checkins FOR DELETE TO authenticated USING (user_id = auth.uid());
  ```
- 公开分享页(anon 可读该用户 `is_public=true` 的记录)—— 追加一条:
  ```sql
  CREATE POLICY select_public ON checkins FOR SELECT TO anon, authenticated
    USING (is_public = true);
  ```
- **profiles 公开可读**(分享页展示昵称/头像/签名;表结构不含敏感字段):
  ```sql
  ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
  CREATE POLICY select_public_profile ON profiles FOR SELECT TO anon, authenticated USING (true);
  ```
  > `DROP POLICY IF EXISTS` 后再 `CREATE POLICY`(PG 无 IF NOT EXISTS)。

### 5.4 统计 RPC(避免前端拉全量)
> 变量: `DB_SCRIPTS="/workspace/.codebuddy/skills/genie-tcb-db-integrator/scripts"`(TCB 数据库脚本目录,与 `docs/工具清单.md` 二节一致)。
```bash
DB_SCRIPTS="/workspace/.codebuddy/skills/genie-tcb-db-integrator/scripts"
bash $DB_SCRIPTS/tcb-pg-function.sh --project-dir /workspace create \
  --name get_travel_stats --args "uid text" --returns json --language sql --volatility STABLE \
  --comment "聚合某用户足迹统计" \
  --body "SELECT json_build_object(
      'total', COUNT(*),
      'cities', COUNT(DISTINCT address),
      'visited', COUNT(*) FILTER (WHERE status='visited'),
      'wish', COUNT(*) FILTER (WHERE status='wish')
    ) FROM checkins WHERE user_id = uid;"
```
前端用 `rpc()` helper 调用(切勿 `db.rpc()`,v3 不存在)。

### 5.5 SDK 使用铁律(防踩坑)
- 初始化:`const db = app.rdb({ database: 'public' })`(不写会报 Invalid schema)。
- 插入**不要** `.insert(...).select()`(TCB 不支持,报 406);要回读就插入后单独查。
- 插入**不要**传 `null`(会覆盖 DEFAULT);缺字段就省略。
- 复杂查询用 `rpc()` helper(`frontend/src/lib/database.ts` 导出),非 `db.rpc()`。

## 7. 地图集成规格(tencent-lbs-integrator 专家)
- 复制 `lib/tencent-lbs.ts` 到 `frontend/src/lib/`。
- **交互地图**(主页):
  ```ts
  import { loadTMapGL, createMap, addMarkerWithInfo, createClient } from '@/lib/tencent-lbs';
  await loadTMapGL();
  const map = createMap(containerEl, { center:{lat, lng}, zoom:5 });
  // 每个 checkin: addMarkerWithInfo(map, {lat,lng}, place_name, infoHtml)
  ```
  容器必须有明确 `width/height`。
- **选点 / 搜索**(新增打卡):`client.searchPlace(keyword, {boundary})`、`client.geocode(addr)`、`client.reverseGeocode(lat,lng)` 自动回填坐标。
- **分享足迹图**:`client.getStaticMapUrl({ center, zoom, size, markers:[{position,color,label}] })`,生成 `<img>` 可下载/转发。
- **错误处理**: 捕获 `LBSError`,按码提示(110/112 白名单、120 未开 WebService、122 配额)。
- **密钥**: 原型用内置共享 Key;发布前请用户申请自有 Key 写入后端 `TENCENT_LBS_KEY`。

## 11. 功能验收点(逐条)
> 优先级标记: **[Must]** 第一期必做 / **[Should]** 建议做(视 §15 Q2) / **[Could]** 增强可选。功能编号 F-01… 与 §23 规则、§11 验收一一对应。
### 11.1 [Must] 地图足迹主页【核心】
- 打开即加载地图并打点;6 类 category 不同色,`wish` 区别样式;点 marker 弹卡→详情。
- 顶部筛选栏按 category/status 过滤生效。
- 依赖: LBS `createMap`+`addMarkerWithInfo`;DB `db.from('checkins').select()`。

### 11.2 [Must] 添加/编辑打卡【核心】
- 搜索/点选→自动填经纬度与地名;`client.reverseGeocode` 补地址。
- 上传照片(对象存储)显示缩略图;必填(地名+坐标+category)缺失拦截。
- 保存:`db.from('checkins').insert({...})`(不传 null、不接 select);成功后地图出新点。
- 编辑可改可删,删除有二次确认。

### 11.3 [Must] 时间线 & 统计【核心】
- 时间线按 `visit_date` 倒序卡片流,可按 category 筛。
- 统计:`rpc('get_travel_stats', {uid})` 出总数/城市数/去过&想去数;category 分布与热区图。

### 11.4 [Must] 分享功能【核心】
- 每条打卡在详情/编辑页可独立勾选「公开」(`is_public=true`);`/me` 生成并复制分享链接 `/share/<uid>`。
- `/share/:publicId` 免登录只读(RLS `select_public`);可一键 `getStaticMapUrl` 生成足迹图下载/转发。
- 上线后稳定链接由「发布为应用」专家提供。

### 11.5 [Later] AI 帮写游记/文案【增强·后置】
- 选若干打卡点 → 后端 `/api/ai/generate` → 混元生成文本,可复制/写入 `mood_text`。

### 11.6 [Later] 智能配图【增强·后置】
- 新增打卡按地名 `img-search` 取封面;或 AI 生成插画风封面。

### 11.7 [Later] 年度足迹回顾【增强·后置】
- 汇总当年打卡 + `getStaticMapUrl` 缩略图 + 混元文字,出图文总结,可分享/可导出 PDF。

### 11.8 [Must] 心愿清单/筛选/点亮【核心·第一期】
- `status='wish'` 地图区别样式;按 category 筛;去过的省份/国家「点亮」成就(前端按 address 规则归类)。

### 11.9 [Later] 第二期:微信小程序【进阶】
- 复用 `checkins` 数据;微信登录(`genie-tcb-auth-miniprogram-integrator`);地图用原生 `<Map>`。
- 账号绑定: 微信登录后关联邮箱,关联网页账号。

## 17. 页面级组件树 · 交互 · 数据流(逐页,开发照此写)

> 通用约定: 所有页面外层包 `<AnimatedRoutes>`(已在 6.3 规定),进入用 `<PageTransition>`;列表/卡片用 `<Stagger>`+`<FadeIn>`;数字用 ReactBits `CountUp`;交互元素用 `<HoverLift>`。任何页面禁止硬编码颜色,统一走 §18 令牌。

### 17.1 地图足迹主页 `/`
- **组件树**: `IndexPage` → `Navbar`(在 AnimatedRoutes 外) + `FilterBar`(category/status 筛选) + `TravelMap`(LBS 容器,必须显式 width/height) + `CheckinList`(侧栏/底栏卡片,`Stagger`)。
- **本地状态**: `filters{category:'all',status:'all'}`、`checkins: Checkin[]`、`selectedId`、`loading`。
- **数据流**:
  1. `useEffect` 内 `const db = app.rdb({database:'public'}); const { data } = await db.from('checkins').select('*')`(RLS 自动仅返回本人;未登录/anon 为空)。
  2. `filters` 变化 → 本地 `checkins.filter(...)`,**不重新查库**。
  3. 渲染: 每个 `checkin` 调 `addMarkerWithInfo(map,{lat,lng},place_name,infoHtml)`;不同 `category` 传不同 `color`,`status='wish'` 用空心/虚线样式。
  4. 点 marker → `setSelectedId(id)` → 弹出 `CheckinCard`(点开进 `/checkin/:id`)。
- **未登录降级**: 显示 3 条示例点位 + 「登录后记录你的足迹」CTA(不读库或读 is_public 样例)。
- **动画**: `TravelMap` 入场 `<FadeIn variants={scaleUp}>`;卡片 `<Stagger>`;筛选切换 marker 用 framer-motion 淡入淡出。
- **依赖**: LBS `createMap`+`addMarkerWithInfo`(§7);DB select(§5)。

### 17.2 新增打卡 `/checkin/new` 与 详情/编辑/删除 `/checkin/:id`
- **组件树**: `CheckinForm` → `PlaceSearchInput`(搜索/地图点选) + `MapPicker`(缩略交互图) + `PhotoUploader`(对象存储) + `TagInput` + `MoodTextarea` + `CategorySelect` + `RatingStars` + `SaveButton`。
- **数据流(新增)**:
  1. 搜索:`client.searchPlace(keyword,{boundary})` 下拉候选;`client.geocode(addr)` 地址→坐标;`MapPicker` 点选→`client.reverseGeocode(lat,lng)` 回填地名/地址。
  2. 照片:`PhotoUploader` 调 TCB 对象存储 SDK 直传,返回 `{url,thumb}` 压入 `photos` 数组(显示缩略图,可删)。
  3. 提交:`db.from('checkins').insert({ place_name,address,lng,lat,category,status,visit_date,mood_text,tags,photos,rating })`(§5.5 铁律: 不接 `.select()`、不传 `null`、缺字段省略)。成功 → `navigate('/')`,地图即时出新点。
- **数据流(编辑)**: `db.from('checkins').select('*').eq('id',id)` 预填;保存 `db.from('checkins').update({...}).eq('id',id)`;删除 `db.from('checkins').delete().eq('id',id)`(带二次确认弹窗)。
- **校验**: `place_name`+`lng`+`lat`+`category` 必填,缺失拦截并提示。
- **动画**: 表单字段 `<Stagger>` 依次入场;提交成功 toast + 页面过渡。

### 17.3 时间线 `/timeline`
- **组件树**: `TimelinePage` → `TimelineFilter`(category) + `TimelineList`(按 `visit_date` 倒序) → `TimelineItem`(日期头 + 卡片 + 封面缩略 + 心情文字)。
- **数据流**: `db.from('checkins').select('*').order('visit_date',{ascending:false})`(本人,RLS);category 筛选本地做。
- **动画**: `<Stagger>` 列表逐项浮现;长列表用 `FadeIn`(滚动进入视口懒加载后续项)。
- **依赖**: DB select + order。

### 17.4 统计 `/stats`
- **组件树**: `StatsPage` → `StatsOverview`(CountUp 数字卡: 总打卡/城市数/去过/想去) + `CategoryDonut`(6 类分布) + `HeatMapCard`(年内足迹热区,复用 LBS 静态图或散点)。
- **数据流**: `rpc('get_travel_stats',{uid})`(§5.4)→ 数字;分类分布 `db.from('checkins').select('category,status')` 本地聚合;热区用 `client.getStaticMapUrl({markers})` 出缩略图。
- **动画**: **所有数字必须用 ReactBits `CountUp`/`Counter`**(ui-animation 强制规则),从 0 滚动到真实值;卡片 `<FadeIn>`。
- **依赖**: RPC + LBS 静态图。

### 17.5 公开分享页 `/share/:publicId`
- **组件树**: `SharePage` → `ShareHeader`(昵称/签名,来自 `profiles`) + `ShareMap`(该用户 `is_public=true` 点位) + `ShareCardList`(精选卡片)。
- **数据流**: `publicId` = 该用户 `user_id`(或 `profiles.id`);`db.from('checkins').select('*').eq('user_id',publicId).eq('is_public',true)`(命中 §5.3 `select_public` 策略,**anon 可读**)。`profiles` 同样加 anon 可读策略。
- **导出足迹图**: 页内「生成足迹图」按钮 → `client.getStaticMapUrl(...)` → `<img>` 可下载/转发(§7)。
- **动画**: `<FadeIn>` 整体入场;`ShareCardList` `<Stagger>`。
- **依赖**: RLS 公开策略 + LBS 静态图。

### 17.6 登录 `/login` 与 我的 `/me`
- **登录页**: `LoginPage` → `EmailOtpForm`(验证码)/`EmailPasswordForm`(密码),用 TCB v2 `signInWithOtp`/`signInWithEmailPassword`(§8);登录成功跳 `/me` 或来源页。
- **我的页 `/me`**: `MePage` → `ProfileEditor`(display_name/avatar/bio,写 `profiles`) + `ShareSwitch`(总开关「允许分享」,并显示并复制分享链接 `/share/<uid>`;每条打卡的「公开」在详情/编辑页独立勾选) + `SettingsList`(登出/分类管理)。
- **动画**: 表单 `<Stagger>`;切换用 `PageTransition`。

## 19. 增强档专家集成明细(精确 API,照此调用)

### 19.1 智能配图(新增打卡封面)
- **方案 A 免费图库**: 后端 `GET /api/images/search?q=<地名>` → 用 `img-search` 的 `ImageSearchService`(Unsplash napi,无需密钥): `result.results.map(r=>r.urls.regular)` 返回 5 张,前端选一张写入 `photos[0]` 作封面。
- **方案 B AI 插画**: 后端 `GET /api/ai/cover?q=<地名>` → `tencent-aiart` 零配置 `const client=createClient(); const url=await client.textToImageSync('旅行插画风 '+地名,{resolution:'1024:1024'})`,返回图链。
- **规则**: 密钥/代理不落前端;封面存 `photos JSONB`。

### 19.2 日出日落 / 黄金时刻(摄影打卡)
- `sunrise-sunset-integrator` 零配置 `createSunTimesClient().getSunTimes({latitude,longitude,date,timeZoneId})` → 详情页展示 `goldenHourMorning/Evening`、`blueHour*`,提示最佳拍摄时段。
- 后端 `GET /api/suntimes?lat=&lng=&date=` 封装;结果可按 `checkins` 缓存减少调用。

### 19.3 天气 / 最佳季节
- `weather` 技能:`wttr.in/<地名>?format=3`(命令行)或前端直接 `fetch('https://api.open-meteo.com/v1/forecast?latitude=&longitude=&current_weather=true')`(JSON,免密钥,CORS 友好)→ 打卡详情/列表显示当地天气;统计页给「最佳出行季节」。

### 19.4 深度攻略 / 行前研究
- `deepresearch-integrator`(零配置): 选打卡点 → 生成带引用的目的地攻略长文,可存为 `mood_text` 扩展或独立攻略页。

### 19.5 一键发小红书
- `xiaohongshu` 技能: 把精选足迹/游记一键发布到小红书(分享增强)。

### 19.6 听游记(TTS)
- `tencent-tts-integrator`(零配置): 读 `mood_text`/游记 → 朗读,出「听游记」播放器。

### 19.7 年度旅行短片
- `tencent-hunyuan-video-integrator`(零配置): 选当年精选照片 → 生成「2026 你的旅行」短片。

### 19.8 导出成册(docx / pdf / pptx)
- `docx` 导出旅行手帐 Word 册;`pdf` 导出相册/地图打印版;`pptx` 生成旅行幻灯片。年度回顾(11.7)可直接复用。

### 19.9 年度回顾(11.7 拼装)
- 汇总当年打卡(`get_travel_stats`)+ `getStaticMapUrl` 缩略图 + 混元文字(§9)+ 可选 `tencent-hunyuan-video` 短片 + `pdf`/`pptx` 导出。

## 23. 业务规则与边界条件(补强: 规则与"不做什么")

### 23.1 业务规则(R)
- **R1 坐标精度**: 经纬度保留 6 位小数;点选/逆地理回填优先于手动输入。
- **R2 状态语义**: `status='wish'`(想去)不计入"去过/城市数"统计,仅统计页单独计数。
- **R3 公开范围**: 公开页仅展示 `is_public=true` 且本人;未开启则分享链接返回"该用户未公开任何足迹"。
- **R4 照片**: 单张 ≤5MB、单次打卡 ≤9 张;对象存储直传,失败可重试单张不整批作废。
- **R5 重复**: 同一用户同名同近似坐标(lng/lat 相差 <0.001)允许存在(不强制去重),保存时提示"已有相似打卡"。
- **R6 时间线排序**: 按 `visit_date` 倒序;空 `visit_date` 排末尾(标记"未标注日期")。
- **R7 分类**: 仅 6 类(scenery/food/culture/city/family/outdoor),见 §15 Q4;标签自由文本、单条 ≤10 个。
- **R8 评分**: `rating` 1–5,可选,缺省不写。

### 23.2 明确"本期不做"(边界,避免范围蔓延)
- 不做好友共建/多人协作地图(第二期及以后)。
- 不做账号互通(Web↔小程序)至第二期。
- 不做打卡评论/点赞/关注等社交互动。
- 不做路线规划/导航(仅展示点位)。
- 不做离线地图(依赖网络加载 LBS)。
- 增强档(§11.5–§11.8)按 §15 Q2 确认后再排期,未确认默认后置。

- 接口: 查询走 RLS 单表,列表分页(每页 20);统计走 RPC 不拉全量(§5.4)。

### 24.2 安全(与 TCB/RLS 一致,见 §5.3)
- 所有数据强制 RLS;密钥(LBS/AI)仅服务端,前端不持。
- 传输 HTTPS;公开页不暴露非公开字段(`address` 仅本人/公开打卡展示)。
- 登录态过期由 AuthContext 拦截跳 `/login`(§8)。

### 24.3 隐私与合规(位置/照片属个人信息)
- 默认私密: 新打卡 `is_public=false`,公开需用户主动开启。
- 删除权: 删除打卡即移出本人与公开页;提供"清空全部"二次确认。
- 最小收集: 仅收集实现功能所需(地点/坐标/文字/照片),不采集设备指纹等。
- 对外分享明示: 公开页在 `/me` 显式提示"开启后他人可看"。

### 24.4 可访问性(遵循 ui-ux-pro-max 对比度)
- 正文对比度 ≥ WCAG AA(`--muted-foreground` 满足);图标 24×24 带文字标签。
- 动效尊重 `prefers-reduced-motion`(§18 已定)。

### 24.5 兼容性
- 浏览器: Chrome/Safari/Edge 最新 2 版 + 移动端 iOS Safari/Android Chrome。
- 断点自查 375/768/1024/1440 无横向滚动(§10)。

## 25. 异常与错误提示设计(补强: 出错时怎么办)

### 25.1 异常场景与处理
| 场景 | 表现 | 处理 |
|------|------|------|
| 网络失败(查询/保存) | 超时/断网 | 顶部轻提示"网络异常,点击重试";本地缓存草稿不丢 |
| 空状态(无打卡) | 地图无点、列表空 | 显示引导卡"记录第一个足迹"CTA |
| 登录过期 | 401/会话失效 | AuthContext 拦截 → 跳 `/login` 并带回跳来源 |
| LBS 配额/错误码(110/112/120/122) | 地图/搜索不可用 | 按 §7 码提示;搜索降级为手动输入坐标 |
| 照片上传失败 | 单张失败 | 仅该张标记失败可重传,不整批作废 |
| 地图容器高度为 0 | 白屏 | 强制容器显式 height,兜底"地图加载失败,刷新重试" |
| 公开页无公开数据 | 分享链接打开空 | 提示"该用户暂未公开足迹" |

### 25.2 错误提示规范
- 不暴露技术栈/密钥;用户可见文案友好中文;危险操作(删除/清空)二次确认。
- 所有可重试动作提供"重试"入口;不可重试明确说明原因。
