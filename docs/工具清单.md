# 工具清单(旅行打卡地图足迹项目)

记录本项目可借用的系统内置「技能 / 连接器」。
- **说明**:本系统的「技能(skill)」即项目可直接复用的专家能力;另有少量通用开发子代理(如设计、测试),按需取用。
- 标注:
  - **核心**: 第一期(Web)或第二期(小程序)必用
  - **增强**: 由 AI/图片/位置等能力支撑,建议做或紧接做
  - **可选**: 看需求再决定是否加
  - **零配置**: 原型阶段无需申请密钥,开箱即用(部分有共用配额/限流,正式发布再换自有密钥)

---

## 一、地图与位置

### tencent-lbs-integrator 【核心 / 零配置】
腾讯地图能力。提供:交互地图显示与打点、地点搜索、地址转坐标(地理编码)、逆地理编码、静态地图图(一键生成足迹地图截图)。
- 对应功能: 地图足迹主页、添加打卡选点、分享足迹图
- 备注: 自带试用密钥,原型直接可跑;正式发布建议换自有 WebService Key

### sunrise-sunset-integrator 【增强 / 零配置】
任意坐标的日出、日落、黄金时刻、蓝调时刻。
- 对应功能: 摄影打卡(提示最佳光线)、某地当日光照信息
- 备注: 经代理网关,无需密钥

---

## 二、数据存储与登录

### genie-tcb-db-integrator 【核心 / 零配置】
TCB 托管 PostgreSQL 数据库。前端 SDK 直接增删改查,按用户隔离(RLS),无需自建服务器;照片存同环境的对象存储。
- 对应功能: 打卡记录、时间线、统计、心愿单全部数据存储
- 脚本目录(建表/RLS/函数): `$DB_SCRIPTS = /workspace/.codebuddy/skills/genie-tcb-db-integrator/scripts`(命令见 `产品方案.md` §5.4 / §16)

### genie-tcb-auth-integrator 【核心 / 零配置】
网页端登录(邮箱验证码 / 邮箱密码 / 手机号)。
- 对应功能: 第一期 Web 登录与数据归属

### genie-tcb-auth-miniprogram-integrator 【核心·第二期】
微信小程序登录(微信一键静默登录 + 邮箱/手机号)。
- 对应功能: 第二期小程序微信免注册登录

### tencent-sms-integrator 【可选 / 零配置】
腾讯云短信,发送验证码。
- 对应功能: 手机号登录的短信验证(登录的备用方式)

---

## 三、AI 智能(文本 / 研究)

### hunyuan-chat-integrator 【增强 / 零配置】
混元大模型(OpenAI 兼容)。文本生成、对话、内容创作。
- 对应功能: AI 帮写游记/朋友圈文案、年度足迹回顾文字、AI 给打卡配文

### web-search-integrator 【增强 / 零配置】
联网搜索(Tavily),可搜实时信息、抽取网页内容。
- 对应功能: 搜目的地攻略/景点信息、给打卡点补充背景资料

### deepresearch-integrator 【增强 / 零配置】
深度研究(腾讯 TokenHub + 联网检索 + 引用来源)。比普通联网搜索更深入,带引用出处、可多轮推理。
- 对应功能: 生成「深度目的地攻略/行前研究」、年度回顾的背景资料调研
- 备注: 零配置可用,适合做有出处的长文攻略

### tencent-asr-integrator 【可选 / 零配置】
腾讯云语音转文字。
- 对应功能: 语音写游记/打卡备注(边走边说,自动成文字)

---

## 四、图片与视觉

### tencent-aiart-integrator 【增强 / 零配置】
腾讯云 AI 绘画(文生图、图生图、风格迁移)。
- 对应功能: 生成插画风封面/地点艺术图

### google-genai-imagen-integrator 【可选 / 零配置】
Google Gemini 文生图与图片编辑(备选图像引擎,与 tencent-aiart 二选一)。
- 对应功能: 备选的高质量封面/插画生成、图片自然语言编辑

### generate-image-by-image 【增强 / 零配置】
图生图 / 风格迁移(腾讯混元)。把现有照片按描述做艺术化改造。
- 对应功能: 把旅行照片转成水彩/油画/插画风封面、统一滤镜、艺术化处理
- 备注: 零配置,适合「照片 → 专属画风」的个性化需求

### img-search 【增强 / 零配置】
免费图库(Unsplash)按关键词搜图,返回图片地址,无需密钥。
- 对应功能: 打卡时自动搜该地美图作封面

### background-remover 【可选】
AI 抠图,输出透明 PNG。
- 对应功能: 把照片抠成地图贴纸/头像素材

### text-to-image 【可选】
AI 生图备选方案(同 tencent-aiart 二选一即可)。

### batch-image-generator 【可选】
批量生成图像资源(包装 text-to-image / generate-image-by-image / background-remover)。
- 对应功能: 开发期批量产出一组风格统一的旅行插画/图标素材
- 备注: 偏「开发素材生产」,终端用户无感,按需使用

### tencent-hunyuan-video-integrator 【可选 / 零配置】
AI 文生视频 / 图生视频(腾讯混元)。
- 对应功能: 把精选打卡照片生成「年度旅行短片」/ 把某张风景图动画化
- 备注: 零配置;视频为异步任务(约 1–5 分钟),URL 24 小时内有效

### tencent-tts-integrator 【可选 / 零配置】
文字转语音(腾讯云 TTS,多种音色、可带情绪)。
- 对应功能: 「听游记」——朗读游记/心情文字,路上闭眼听

## 五、设计与模板

### web-implement 【核心】
网页应用模板(React + Vite + Tailwind + TCB),第一期基于此搭建。

### frontend-design / web-design-guidelines 【可选】

### tabbar-icon-generator 【核心·第二期】
生成小程序底部 TabBar 图标(81×81 PNG,普通/选中两态)。
- 对应功能: 第二期小程序导航图标(首页/记录/我的)

## 九、开发规范保障(减少出错、保证代码质量)

> 本类不是「给产品加功能」的工具,而是约束开发过程、降低出错率、保证代码规范的保障手段。开工后默认启用。

### 1. 标准地基 — web-implement 【核心】
网页模板(React + Vite + Tailwind + TCB)自带定好的目录结构、构建配置、前后端联调方式。
- 作用: 从已知、可运行的结构出发,挡掉结构性错误和配置坑,避免每次重新搭建带来的混乱。

### 2. UI 规范 — ui-ux-pro-max / web-design-guidelines / frontend-design 【核心·可选】
把配色、字体、间距、组件规范、UX 最佳实践固化为可照做的清单。
- 作用: 界面风格统一,不写出临时拼凑的样式。

### 3. 数据安全最佳实践 — genie-tcb-db-integrator / genie-tcb-auth-integrator 【核心】
这两个技能自带「安全最佳实践」章节(数据库强制行级权限 RLS、密钥不落前端)。
- 作用: 数据权限与登录安全不踩坑,按指引走即合规。

### 4. 环境自带的「自动质量门」(非技能,但最硬)
- **停止钩子(Stop Hook)+ 就绪检查**: 每改一次代码,系统自动检查页面能否打开、有无 JS 运行时报错,出错即拦住。
- **项目规则** `.codebuddy/rules/genie-troubleshooting.mdc`: 排错流程的硬约束,逼我按规范定位问题。
- **代码审查子代理 + Git 连接器**(github / cnb / gongfeng-connector): 重要改动可派「代码审查」子代理复查,或走 Pull Request 流程再合并。

### 开发期质量保障约定(开工后执行)
1. 以 `web-implement` 打底,`ui-ux-pro-max` 定风格。
2. 每次改完靠「停止钩子」自动校验,页面与运行时错误即时拦截。
3. 关键模块(地图、数据、登录)再派「代码审查」子代理过一遍。
4. 重大改动走 Git 连接器提交 / PR,留可回溯记录。
